## 🚀 About This Project

This is my personal **developer portfolio website** created to showcase my skills, projects, and learning journey as a **Full MERN Stack Developer**.

The main purpose of this portfolio is to create a professional digital identity where recruiters, clients, and developers can explore my work, technical skills, and real-world projects.

The website focuses on modern UI design, responsive layouts, smooth animations, and a clean user experience.
